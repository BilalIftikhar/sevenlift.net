# Seven Lift: Keyword Map

One main keyword per page. Before writing a new page or post, check this list:
if the keyword is already taken, improve that page instead of writing a second
one. Two pages chasing the same keyword compete with each other and both rank
worse.

Search volumes still need checking in a keyword tool set to the UAE. The
keywords below were chosen from what customers ask and what the pages cover,
not from measured data.

Rules that apply to every page (from the SEO reviewer):

- No em dashes in titles, descriptions or copy.
- UAE-wide pages target UAE-wide keywords only and never name cities.
- City pages need genuinely different copy, not a city name swapped in.
- No keyword lists in the footer or sidebars.

## How guides feed the money pages

Every guide links into two to four service or location pages. Those pages
automatically show the guides that link to them in a "Planning Guides"
section (`components/related-guides.tsx`), so each link works in both
directions. When you write a new guide, link to the pages it is genuinely
about. The reverse links then appear on their own.
